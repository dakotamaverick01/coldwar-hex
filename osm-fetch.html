Hof Gap map download

This page asks the free OpenStreetMap servers for the rivers, roads, railway and forests of the game's 15 x 15 km box. It asks in 9 small pieces, retries by itself, and lets you save the result as one file on your iPhone. Then you attach the file in the Claude chat.

Step 0 (30 seconds): test the servers
Sends a tiny question to each server so we can see which one answers from your phone. If you screenshot the result for Claude, that tells us exactly what is blocked.
File 1: rivers, roads, railway, forests, water
9 pieces, about 3 to 8 MB in total, a few minutes. Keep this page open and the screen on. If some pieces fail, tap the button again: it only asks for the missing ones.
File 2 (later): building outlines for one mission area
Not needed yet. After we pick the bridge location, Claude will give you the two numbers to type in here. It asks for a square about 3 km wide, which is small and quick.
Then, in the Claude chat
Tap the + button, tap Files, open Downloads, and pick the file (hof_osm_map.json, later hof_osm_buildings.json). Send it with the message "attached".
