Hof Gap map download

This page asks the free OpenStreetMap server for the rivers, roads, railway, forests and buildings in the game's 15 x 15 km box, and lets you save the result as a file on your iPhone. Then you attach the file in the Claude chat.

File 1: rivers, roads, railway, forests, water
Usually 3 to 8 MB. Takes up to a minute.
File 2: building outlines
Usually 5 to 15 MB. Takes up to two minutes. Keep this page open and the screen on.
Then, in the Claude chat
Tap the + button, tap Files, open Downloads, and pick both files (hof_osm_map.json and hof_osm_buildings.json). Send them with the message "attached".
